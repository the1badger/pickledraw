Pickle Draw — how to run a session

        
Pickle Draw works out who plays with whom, on which court, for every round of a
          social session. It tries to give everyone the same number of games, a different
          partner each time, and a fair share of sit-outs. It runs on your phone or tablet
          and keeps everything on that device.


        
1. Start a session

        
    
          
  1. Give it a name if you like — "Thursday morning mixer". The date and time
            fill themselves in, so change them only if you are setting up ahead.
    2. 
          
  2. Get the players in. There are four ways, and you can mix them:
            
      
              
    • Type them, one name per line.
      • 
              
    • Paste a list copied from a spreadsheet or an email. Commas, tabs and
                semicolons all work, and it sorts them onto one name per line for you.
      • 
              
    • Read from a screenshot. Take a screenshot of the Opensports attendee
                list, tap this and choose the picture. It reads the names and shows you a
                tick-list to confirm. If the list is too long for one screenshot, take two and
                read them both in — anyone appearing twice is flagged.
      • 
              
    • Example list puts thirteen made-up players in, for a practice run.
      • 
            
    
          
    3. 
          
  3. If your club uses levels, put the number after the name — Bri Taylor 3.5.
            This is optional and only matters if you choose one of the level-aware mixes.
    4. 
        


        
2. Set up the session

        
    
          
  • Courts in use — how many are yours this morning.
    • 
          
  • Format — doubles (four a court) or singles (two).
    • 
          
  • How to mix:
            
      
              
    • Pure social ignores levels. Everyone plays with and against everyone.
      • 
              
    • Even teams still mixes everyone up, but tries to make the two sides of
                each net add up to about the same level.
      • 
              
    • Similar levels keeps each court to players of a similar standard, so the
                stronger and gentler courts sort themselves out.
      • 
            
    
          
    • 
          
  • How many rounds — either set a number, or let it work out from how long
            you have. It allows for the changeover between games, and shows you the sum.
    • 
          
  • Per game and Changeover — the game length also sets the on-court
            timer.
    • 
          
  • Time-up sound — beeps, a siren, or silent. Silent still buzzes the phone.
            Tap Try it to hear it before you commit.
    • 
        

        
Then tap Build the draw.


        
3. On the courts

        
    
          
  1. The screen shows the current round: each court, with team A against team B, and
            anyone sitting out underneath.
    2. 
          
  2. Tap Start a 12 minute game (or whatever you set). The screen goes dark with a
            big countdown, the session name, and the pairings for all courts. It keeps the
            screen awake, beeps once at a minute to go, and sounds at the end.
    3. 
          
  3. When time is up the sound plays and it moves itself on to the next round. If you
            would rather do it by hand, tap Finish round.
    4. 
          
  4. The arrows move between rounds. Moving forward marks a round as played, and played
            rounds never change afterwards. The padlock lets you correct that.
    5. 
        


        
4. When things change — tap a player's name

        
    
          
  • Put on a court — place somebody on a particular court for the next round
            and the rest of that round is drawn around them. Place up to a full court.
    • 
          
  • Keep apart from — tick anyone who should not share a court with them, for
            the rest of the session.
    • 
          
  • Sitting out the next round or the next two — for someone who needs a
            breather. They come back on by themselves.
    • 
          
  • Gone home for the day — takes them out of everything from here on.
    • 
          
  • Tap anyone who is off to put them straight back on.
    • 
          
  • A latecomer goes in the Add a latecomer box. They will be given games
            straight away to catch up.
    • 
        

        
Every one of these redraws the rounds that have not been played yet, and leaves the
          played ones alone.


        
5. Other things worth knowing

        
    
          
  • Add a round if you have time to spare; it keeps everything already drawn.
            Drop last round does the opposite.
    • 
          
  • Whole draw shows every round at once, and Print gives you a paper copy
            with the session name and date on it.
    • 
          
  • How good is this draw shows games each, repeat partners and sit-outs, so you
            can see it is being fair.
    • 
          
  • Redraw everything puts every round back in the hat. Change setup lets you
            alter the settings and build again. New session clears the lot and starts fresh.
            All three ask first.
    • 
          
  • The session saves itself as you go, so a flat battery or a closed app is not a
            disaster — when you come back it offers to pick up where you left off.
    • 
          
  • Names on the courts are shortened to first names, and a surname initial is added
            if two people share a first name.
    • 
        


        
6. If something is not right

        
    
          
  • If reading a screenshot goes wrong, tap Show what happened at the bottom of
            the setup page. It records exactly what was read, and Copy this log puts it on
            the clipboard so you can send it on.
    • 
          
  • Reading a screenshot needs a connection the first time, to fetch the text reader.
            After that it works without one. Everything else works with no signal at all.
    • 
          
  • At the bottom of the page it says whether the app is saved on this device or
            loading from the web, along with its version. Check for a newer version looks
            to see whether a newer one has been published.
